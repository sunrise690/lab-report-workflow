# 数据与现场记录

## 预习与记录表

先从轮值/分组信息和当前指导书确认实验编号与题目，不能仅按上一周顺推。预习说明要能用于现场：测什么、仪器如何连接、怎样读数、单位与档位、测量组次和必要注意事项。课程要求的示意图与操作顺序以当前讲义为准。

现场Excel将用户输入与派生公式分开，表头写清样品、条件、单位、组次和位置；已知公式写入可编辑单元格，便于输入后计算，不能只给静态计算值。未输入的数据保持空白，防止零值、除零或缓存结果冒充测量。用已知样例检查公式、单位换算和引用范围；遵循表格技能的计算与显示规则。

用户需要科学计数法时设置真实数字格式，不把数字拼成无法计算的文本；要求WPS适配时选择兼容公式并检查显示和引用，不假定只有Excel能打开。光谱名称、正侧/横竖方向、补测与首次测量标签按最新确认记录保留，不从文件简写自行推断。

## 提取与对应

按当前请求保留原表行列、合并表头、文字和顺序；Word交付应是真表格而非表格截图。若用户要求转置，保留原数据对应关系，不自动转置所有实验表。

逐项记录文件/表号/行列、原始文字、单位、实验项目、样品/条件、采集组次、状态及对应图。重叠截图只去掉重复转录的行，不删除原图；同字节文件也可能有不同实验语义。

用户明确的文件命名、组次和时间顺序可作为对应依据，辅以软件标签、行序与现场说明核对。文件修改时间、ZIP条目时间和EXIF时间分别标记来源，不能都称为拍摄时间。遇到缺失映射，只暂缓相关图或值，继续其余可确定部分。

辅助脚本从技能目录调用，路径按任务设置：

```text
python scripts/inventory_lab_sources.py INPUT_DIR --hashes --out inventory.json
python scripts/extract_docx_records.py SOURCE.docx --out records.json --media-dir media
```

需要子目录时显式加--recursive。清点工具只取文件和图像头部信息。Word工具保留段落、顶层和嵌套表结构、父单元格位置及原嵌入图片字节，不自动推断图像含义或计算像素统计。

## 数据处理与更正

只提取、转录或对应时，不自动新增拟合和误差分析。用户要求计算或完整报告时，从已确认记录计算所需均值、标准差、比值、归一化或误差，说明样本范围、单位、基准和分母。软件原指标与另按公式计算的量分列。

不因数量级看起来异常就移小数点、猜单位、换列、改档位或移动横坐标。用户明确更正后保留原值与更正关系，再同步受影响的计算、表格和曲线。测量失败按事实写“未能测得”；未记录不填0；明确未做且未要求的项目不扩大为缺项。

用户提供参考报告中的数据并要求提取或检查时，可完成该数据任务，同时保留来源身份；制作本人的报告时，以其后来指定的实测记录为基线。示例、估计、拟合与修图交付另存，不把它们自动提升为实测。

合理性检查需区分采样稀疏、零点、档位、漂移和物理模型的影响。插值连接不增加测点，拟合曲线不代替原观测；不能为了曲线平顺而改读数，或用少量点认证本征线性度、硬件饱和及动态范围。
