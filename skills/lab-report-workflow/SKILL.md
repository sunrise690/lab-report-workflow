# 实验报告工作流

默认简体中文。先确认当前阶段和实验题目，再读取相关规范。沿用上一份时查看实际成品、活动源码和用户最后确认的要求；有现成信息就直接继续，不重复询问。

## 按任务选择流程

| 当前请求 | 交付与需要读取的规范 |
|---|---|
| 预习、做现场记录表 | 实验项目、原理、接线/读数方法、可编辑输入表与所需公式；读[数据与记录](references/data-records.md)和对应课程规范 |
| 提取到Excel、原表到Word、先对应图片 | 原值、完整表格及来源对应；只做当前整理，不自动开展分析或写完整报告；读[数据与记录](references/data-records.md) |
| 检查数据、计算误差 | 从已确认记录计算必要结果，说明口径和异常；读[数据与记录](references/data-records.md) |
| 写报告、完善逻辑与语言 | 当前源、正式报告及指定附加版本；读[报告与图表](references/report-writing.md)、对应课程规范和[渲染交付](references/rendering.md) |
| 抄写/留白打印版 | 按当前用途保留封面、图表、标题和书写定位；读[渲染交付](references/rendering.md) |
| 整理实验文件夹 | 分类、版本与路径依赖、文件完整性；只读[文件归档](references/file-organization.md)，不重写或重编译报告 |

课程规范：[光电检测](references/opto-course.md)、[微波实验](references/microwave-course.md)。封面字段、字体与个人配置见[课程格式](references/course-profile.md)。其他课程依据自己的讲义和模板，不自动套用这两门课的单次细节。

## 决策顺序

- 当前明确要求优先；同一实验后续更正覆盖对应旧值或旧要求。记录其作用对象，不让某次更正修改其他实验。
- 实测记录、用户确认的Word/表格与最新补充构成数据基线；参考报告仅按指定范围借鉴格式、原理或待提取内容，不成为用户自己的实测数据。
- 历史要求分为通用流程、课程偏好、当次事实和已被覆盖的要求。机型、组数、页数、图数、某次刻度、一次拟合或修图授权均不能直接升级为永久默认值。
- 对“这个删掉”“这样不好看”等局部指示，核对所指截图与上下文。旧截图不可访问时保留不确定性，不猜测其具体字体、尺寸或条目。

## 数据与图像边界

- 保留原值、原始文字、单位、采集顺序及出处。空白、0、“未记录”“未能测得”“未要求做”分别处理；未要求的项目不加进正文缺项清单。
- 原始量、派生量、用户更正及示例/模拟量分开。缺测不自动补成独立实测；后来补充的真实数据要替换已弃用的估计结果。
- 对应和展示照片时保留原始字节、亮度、颜色和对比度，不从转发或压缩照片重算像素覆盖软件记录。新图像分析、改指针等编辑只在用户明确要求的任务范围执行，保留源图与编辑产物对应，不能当作新增实测证据。
- 遵守用户的本地视觉模型隔离要求，不自动调用、探测、启动或推荐本地视觉模型；再次明确授权仅限指定场景。页面检查用当前可用的图像查看工具，不把模型服务设为必经步骤。

## 完成标准

报告语言正式，公式、数据、图表和物理解释相互对应。只改文字时不重算确认数据或重处理原图；修订在当前项目继续，按用户要求同步正式版、抄写版及源包。

内容或排版变更后编译、渲染并逐页查看；仅移动且哈希不变的文件做归档核验。按任务使用可用的文档、PDF、表格、绘图技能与工具；用户指定MATLAB等后端时遵循该选择。

最终链接指向确实存在的当前文件。源包可重建、当前PDF副本内容一致；不把渲染页、依赖缓存、聊天记录或个人配置混入公开交付。
